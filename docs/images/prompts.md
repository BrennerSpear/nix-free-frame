# Illustration provenance

These two illustrations were made with the built-in image-generation tool and visually reviewed. They contain generic artwork, not personal photos or verified teardown photography. The USB scene is a schematic, not a map of a particular board. Final assets are `how-it-works.png` and `usb-setup.png` in this directory.

## Architecture prompt

Create a polished, simple human-readable architecture illustration for a GitHub README titled Nix Free Frame. Wide landscape 16:9, off-white background, charcoal typography, soft sage and muted sky-blue accents, crisp clean editorial illustration, generous whitespace, no accent sidebars. Three large nodes left-to-right: stylized cloud with colorful generic photograph tiles labeled exactly “Google Photos album” and a small caption “Shared link”; simple silver Mac desktop computer labeled exactly “Your Mac” and small caption “Daily sync + local photo server”; a landscape digital photo frame displaying a GENERIC illustrated mountains-and-sun landscape, labeled exactly “Your Nixplay frame” and small caption “Offline slideshow cache”. Show a clear solid directional arrow from cloud to Mac, caption “Internet”, and solid arrow from Mac to frame with Wi-Fi glyph and caption “Home Wi-Fi”. A separate thin dashed connection BELOW the Mac and frame, with recognisable micro-USB-B data cable icon, caption exactly “One-time USB setup”. At bottom small plain sentence “The Mac fetches photos. The frame keeps a copy and plays them offline.” Do not depict the USB cable as ongoing power or ongoing photo delivery. The frame uses its own original power supply, not powered by Mac. No personal photographs, no IP addresses, no code, no brand logos except text naming Nixplay. The diagram is the complete output, no poster border. Make all labels highly legible at GitHub desktop width.

## USB prompt

Create a restrained instructional illustration for a GitHub hardware setup guide, landscape format, white background, dark clear sans-serif text, soft sky-blue and sage palette matching a clean computer/network diagram. Main heading exactly “Connect once by micro-USB”. Three panels numbered 1, 2, 3 left to right. Panel 1 label “Unplug power”: generic digital photo frame on a work mat beside a disconnected barrel power adapter. Panel 2 label “Open carefully”: schematic generic photo-frame casing opened with a plastic pry tool, with a small green circuit board exposed and a micro-USB-B socket indicated by a magnifying bubble. DO NOT show screw locations, number of screws, an exact board layout, or claim this is a photograph of a Nixplay model. Panel 3 label “Use a data cable”: close-up illustration of a genuine micro-USB-B male connector, small flat trapezoidal metal tip with five contact positions, and a cable connecting the frame to a Mac computer. Clearly distinguish micro-USB-B from USB-C: micro B has asymmetric shallow trapezoid form, not an oval; do not substitute a USB-A tip for the close-up. Small footer exactly “Schematic only. Port and screw placement vary by revision; follow the linked teardown.” No code, no actual device photos, no personal images, no technical dimensions, no logos, no decorative side rules. Clear usable diagram with minimal text and generous space.
