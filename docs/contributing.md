# Working on Nix Free Frame

Keep album links, tokens, keys, photos, screenshots, APK baselines and recovery evidence private and ignored. `.env.example` must contain placeholders only. Maintain exact package/signature trust checks and bounded same-origin updates. Do not add arbitrary command execution, network ADB, public ports, account wipes or firmware flashing.

Use the existing Bun/TypeScript host and Java Android client. The host is macOS-only. Run relevant unit/type/lint/build checks, the public-safety audit and actual readback before claiming an operation passed. Device actions need an explicitly selected compatible USB target and preserved original state. Keep physical/manual/unverified recovery steps distinct from automated checks.

Do not publish the original local Git history. Prepare a fresh sanitized export, review it, choose the project license and obtain explicit publication direction. Preserve third-party license notices and download tools rather than committing private/vendor binaries.
